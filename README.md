# COREBURN - developer / testing build

**Not the public game.** Live game: https://sublebow.github.io/coreburn/

Dev build: https://fatalbananas7.github.io/coreburn-dev/ (dev panel always on, `DEV BUILD` badge, noindex).

- `devtools/` = the only copy of the dev-only files (dev-boot sandbox + badge, dev-tools panel, 5C inspector, harness hook).
- Everything else is generated by `node scripts/publish-dev.mjs` in the main repo (SubLebOw/coreburn). Don't edit it here.
- Saves: this site is a different origin, so it never sees the live game's saves; on top of that dev-boot keeps each tab's
  changes in a throwaway sessionStorage sandbox, and dev runs never submit scores.
